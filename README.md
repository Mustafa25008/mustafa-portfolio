# Mustafa's Portfolio

Welcome to my personal portfolio project!  
This site showcases my projects, skills, and achievements as a software developer.

## Project Info

**Live URL**: [Portfolio Website](https://mustafas-portfolio.vercel.app/)

## Getting Started

You can edit and run this project locally using your preferred IDE.

### Prerequisites
- [Node.js](https://nodejs.org/) (with npm)

### Installation

```sh
# Step 1: Clone the repository using the project's Git URL
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd <YOUR_PROJECT_NAME>

# Step 3: Install the necessary dependencies
npm install

# Step 4: Start the development server with auto-reloading and an instant preview
npm run dev
````

## Editing Files

* Edit files directly in your local IDE (VS Code recommended).
* Or edit directly on GitHub by clicking the **pencil icon** on any file.
